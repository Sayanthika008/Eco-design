This project presents a redesign of a disposable college event badge. A durable holder and clip are reused across events, while a small recycled-paper insert is replaced for each attendee. A check-out return loop helps collect badges for cleaning and reuse; at end of life, the parts can be separated for recovery where local recycling streams accept them.
